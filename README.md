About me

I’m a software developer from Jamnagar, India, currently pursuing my BCA and exploring the space between practical software, creative projects, and developer tooling. I enjoy turning ideas into clean, useful experiences—whether that means building a Minecraft resource plugin, a multiplayer game, an offline utility, or a tool that makes development workflows less messy.

•
🔭 I’m currently working on DynamicEconomy, a standalone marketplace resource plugin for Minecraft Java Edition.

•
🌱 I’m learning advanced Java concepts and modern web development.

•
