About me

I’m a software developer from Jamnagar, India, currently pursuing my BCA. I enjoy building practical software that solves small everyday problems, experimenting with automation, and creating projects around gaming and developer workflows.

My recent work ranges from privacy-first browser utilities and offline desktop applications to Discord bots, pull-request analysis tools, multiplayer games, and command-line utilities. I like projects that are useful, focused, and easy to understand.

•
🔭 I’m currently building small tools, bots, and experiments that combine automation with clean user experiences.

•
🌱 I’m learning more about modern web development, JavaScript ecosystems, automation, and software design.

•
💬 Ask me about JavaScript, HTML, CSS, Python, Flutter, Discord bots, Minecraft development, or developer tools.
